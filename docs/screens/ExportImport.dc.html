OpenAPI としてエクスポート

形式
変換ルール
シークレットの値は書き出しません。SESSION などは securitySchemes の定義だけが出力されます。

プレビュー

openapi.yaml · 88 operations 
openapi: 3.0.3
info:
  title: 日本アニメーション ライセンス契約管理システム API
  version: 0.1.0
servers:
  - url: http://localhost:8080
    description: ローカル (Dev Container)
security:
  - cookieAuth: []
tags:
  - name: video-client
  - name: auth
paths:
  /api/v1/video/clients:
    get:
      tags: [video-client]
      operationId: getClientList
      summary: 取引先一覧取得
      parameters:
        - name: q
          in: query
          schema:
            type: string
      x-app:
        savedValues:
          q: Netflix
          perPage: 20
components:
  securitySchemes:
    cookieAuth:
      type: apiKey
      in: cookie
      name: SESSION
インポートは OpenAPI ファイルから行います。x-app 拡張があれば設定も復元されます。 インポートへ キャンセル
